# Gentoo Update Manager v1.2.0 — Plasma Dashboard Redesign

- Redesigned the Qt interface around the supplied Asahi Control Center visual reference.
- Added a left navigation sidebar for Overview, Updates, Installed Software, and Held Back.
- Added an overview dashboard with live counts of available updates, installed packages, and hold rules.
- Introduced purple-on-dark cards, a highlighted active navigation state, and a persistent Portage status panel.
- Moved maintenance actions into the sidebar and kept transaction, search, package details, and technical output features.
- Retained the blue Gentoo application icon and Plasma launcher refresh during installation.

This is a visual redesign of the existing application. It has passed static Python syntax checks but has not been run on a live Gentoo Plasma desktop.
